# 🚀 Proyecto de Integración: Node.js y Supabase con Interfaz Web

Práctica escolar desarrollada para conectar una aplicación local y un formulario web interactivo con una base de datos en la nube utilizando **Supabase**.

---

## 🛠️ Tecnologías y Herramientas Utilizadas
* **Node.js** para la ejecución de scripts del lado del servidor.
* **Supabase** como plataforma de base de datos en la nube (PostgreSQL) y sistema de autenticación.
* **HTML5 y JavaScript (Vanilla)** para la interfaz web interactiva con autenticación básica.
* **Live Server (VS Code)** para el entorno de desarrollo local.
* **Git y GitHub** para el control de versiones y repositorio.

---

## 📁 Estructura del Proyecto
* `index.js` - Script de Node.js para inserción y consulta directa en la base de datos.
* `index.html` - Interfaz web con formulario interactivo y autenticación básica de usuarios.
* `README.md` - Documentación del proyecto.

---

## ⚙️ Instrucciones de Configuración y Ejecución

1. Clonar el repositorio en tu computadora:
   ```bash
   git clone [https://github.com/tu-usuario/tu-repositorio.git](https://github.com/tu-usuario/tu-repositorio.git)
2. Instalar las dependencias necesarias para Node.js:
   ```Bash
   npm install @supabase/supabase-js
3. Ejecutar el script local de prueba:
   ```Bash
   node index.js
